Cookie Notice

The Demand Range website is a static site with no advertising tags or non-essential cookies. Cloudflare, which delivers the site, adds a cookieless page-view analytics script.

Current posture: no advertising pixels, retargeting tags, heatmaps, session replay or chat widgets are installed, and no cookies are set on a normal visit. The one third-party script is Cloudflare Web Analytics, described in section 1. The site does not display a cookie-consent banner.

1. Current cookies and similar technologies

The public Demand Range website uses static HTML, a local stylesheet, a local favicon and inline scripts for the light/dark theme toggle and the quote-request form. Its own code has no user accounts, ecommerce, analytics, advertising or behavioural profiling.

The quote client validates entries, sets a per-page submission token and load time in form fields, and reads the optional asset_ref and campaign_ref URL values into hidden fields. It does not write browser storage.

The site is hosted on GitHub Pages and delivered through Cloudflare’s network. Cloudflare adds its Web Analytics script to each page as the page is delivered. The script counts page views and measures page-load timing, and Cloudflare states that it does not use cookies or local storage. Cloudflare’s responses also carry a Network Error Logging header, which asks supporting browsers to report failed connections to Cloudflare. No cookies were set by the site or by Cloudflare when we checked on 28 October 2026. Cloudflare may set a strictly necessary cf_clearance cookie if it shows a visitor a security check; see Cloudflare’s cookie list. Hosting, browser, DNS, security and email systems may still process technical data needed to load and protect the site; see the Privacy Notice.

3. Site resources

Fonts use visitors' system font stack. The pages do not request external fonts or images. The only external script is the Cloudflare Web Analytics script, loaded from static.cloudflareinsights.com. The quote form is part of the page, not an embedded third-party form. On a valid submission, the browser sends the information you choose to submit to the configured Google Workspace form-processing endpoint; see the Privacy Notice for enquiry processing. Clicking an email link opens the visitor's configured email application. The light/dark toggle stores the chosen theme in the browser's local storage on the visitor's own device; the theme preference is not transmitted to Demand Range or any third party. This theme behaviour is separate from submitting a quote request.

4. Why there is no banner

The site sets no advertising or tracking cookies, and Cloudflare Web Analytics, as Cloudflare describes it, stores nothing in your browser. The only site-code storage is the colour preference you explicitly request using the light/dark toggle; it is used solely to remember that choice. You can change it with the toggle or clear it using your browser's site-data controls. Any additional storage or tracking will be reviewed before it is introduced.

5. If tracking is added later

Any additional analytics, advertising, third-party embedded forms, chat, session replay or other non-essential tracking must be reviewed before activation. This notice and an appropriate consent mechanism must be added where required.

For cookie or privacy questions, contact partners@demandrange.com.

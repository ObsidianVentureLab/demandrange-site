Cookie Notice

This notice explains the current cookie and tracking posture for the public Demand Range website.

Current posture: Demand Range does not currently set non-essential cookies through its own website code and does not currently run advertising pixels, analytics cookies, retargeting tags, heatmaps, or chat widgets. Because of that, the site does not currently show a cookie-consent banner.
1. Current cookies and similar technologies 2. Current technology table 3. External resources 4. Why there is no banner now 5. What happens if tracking is added later 6. Contact

1. Current cookies and similar technologies

The public Demand Range website is a static informational website. It uses simple HTML/CSS/JavaScript for page rendering and navigation. We do not currently use our own first-party cookies for user accounts, ecommerce, analytics, advertising, or behavioural profiling.

Hosting, browser, DNS, security, and email systems may still process normal technical data needed to load and protect the website. That is covered in the Privacy Notice.

3. External resources

The homepage may request Google Fonts resources from fonts.googleapis.com and fonts.gstatic.com so the page renders as designed. Those requests are made by your browser. Demand Range does not use those font requests for advertising, retargeting, behavioural profiling, or lead identification.

4. Why there is no banner now

Irish Data Protection Commission guidance states that consent is normally required for cookies or similar technologies unless they are strictly necessary to provide a service requested by the user. Because this site currently does not set non-essential cookies or tracking tags through our own code, a cookie-consent banner would add friction without providing a real choice to control optional cookies.

5. What happens if tracking is added later

If we later add analytics, advertising pixels, embedded forms, chat widgets, session replay, retargeting tags, or other non-essential cookies/similar technologies, we will review the setup before enabling it, update this notice, and add an appropriate consent mechanism where required.

No future marketing, analytics, or tracking tool should be added to the public site without a cookie/privacy review first.

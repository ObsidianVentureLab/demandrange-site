Cookie Notice

The current Demand Range site is a dependency-free static website with no analytics, advertising tags or non-essential cookies in its own code.

Current posture: no analytics, advertising pixels, retargeting tags, heatmaps, session replay, chat widgets or third-party scripts are installed. The site therefore does not display a cookie-consent banner.

1. Current cookies and similar technologies

The public Demand Range website uses static HTML, a local stylesheet and a local favicon. It has no user accounts, ecommerce, analytics, advertising or behavioural profiling code. Hosting, browser, DNS, security and email systems may still process technical data needed to load and protect the site; see the Privacy Notice.

3. Site resources

Fonts use visitors' system font stack. The pages do not request external fonts, images, scripts, analytics or embedded forms. Clicking an email link opens the visitor's configured email application.

4. Why there is no banner

Because the current site code does not set non-essential cookies or tracking tags, a consent banner would not provide a meaningful optional-cookie choice.

5. If tracking is added later

Any future analytics, advertising, embedded forms, chat, session replay or other non-essential tracking must be reviewed before activation. This notice and an appropriate consent mechanism must be added where required.

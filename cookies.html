Cookie Notice

The current Demand Range site is a dependency-free static website with no analytics, advertising tags or non-essential cookies in its own code.

Current posture: no analytics, advertising pixels, retargeting tags, heatmaps, session replay, chat widgets or third-party scripts are installed. The site therefore does not display a cookie-consent banner.
1. Current technologies2. Technology table3. Site resources4. Why no banner5. Future changes6. Contact

1. Current cookies and similar technologies

The public Demand Range website uses static HTML, a local stylesheet, a local favicon and a small inline script for the light/dark theme toggle. It has no user accounts, ecommerce, analytics, advertising or behavioural profiling code. Hosting, browser, DNS, security and email systems may still process technical data needed to load and protect the site; see the Privacy Notice.

3. Site resources

Fonts use visitors' system font stack. The pages do not request external fonts, images, scripts, analytics or embedded forms. Clicking an email link opens the visitor's configured email application. The light/dark toggle stores the chosen theme in the browser's local storage on the visitor's own device; nothing is transmitted to Demand Range or any third party.

4. Why there is no banner

The site has no analytics, advertising or tracking choices to present in a banner. The only site-code storage is the colour preference you explicitly request using the light/dark toggle; it is used solely to remember that choice. You can change it with the toggle or clear it using your browser's site-data controls. Any additional storage or tracking will be reviewed before it is introduced.

5. If tracking is added later

Any future analytics, advertising, embedded forms, chat, session replay or other non-essential tracking must be reviewed before activation. This notice and an appropriate consent mechanism must be added where required.

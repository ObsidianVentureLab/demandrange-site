CPV codes for pumps, valves and industrial equipment

By Demand Range research team · Last reviewed 28 October 2026

Short answer: most industrial equipment tenders sit in CPV division 42 (Industrial machinery). Pumps are 42122000, valves 42130000 and valve actuators 42132100. Instruments sit in division 38, pipework in 44, plant construction in 45, and repair and installation in 50 and 51. Alert on your exact product codes, then add the works and maintenance codes buyers bundle them into.

Key facts (CPV 2008 and the portals' own guidance; checked 28 October 2026)

  • The EU's Common Procurement Vocabulary, CPV 2008, was adopted by Regulation (EC) No 213/2008 and has been in use since 17 September 2008.[1][2]
  • In CPV 2008, pumps are 42122000, taps, cocks, valves and similar appliances are 42130000, and valve actuators are 42132100, all in division 42 (Industrial machinery).[1][3]
  • A CPV code has eight digits plus a check digit, and TED's guidance says a buyer picks a single code for the notice title, using a more general one where no code is precise enough.[2]
  • Since a July 2024 release, Irish eTenders matches CPV alerts on the code tree, but two different sub-codes in the same tree do not match.[5]

01 / how a cpv code is built

How a CPV code is built

The Common Procurement Vocabulary (CPV) is the EU's classification for what a public contract buys, adopted as CPV 2008 by Regulation (EC) No 213/2008 and in use since 17 September 2008.[1][2] A code has eight digits and a check digit:[2]

  • the first two digits are the division (42000000 Industrial machinery);
  • the first three are the group (42100000 Machinery for the production and use of mechanical power);
  • the first four are the class (42120000 Pumps and compressors);
  • the first five are the category (42122000 Pumps);
  • the last three add precision within the category (42122130 Water pumps), and the ninth digit after the dash only verifies the others.

Two rules from TED's guidance matter when you search. A buyer must pick a single code for the notice title, and where no code is precise enough it uses a more general one, "recognised because it has more zeros".[2] So the same pump tender can be coded 42122000 by one buyer and 42120000 by another. Search the parent as well as the exact code.

The tree is not always intuitive. In the official vocabulary, 42122220 Sewage pumps sits under 42122200 Reciprocating positive-displacement pumps for liquids, and 42997300 Industrial robots sits under 42997000 Pipeline machinery.[3] Check a code's actual parent before assuming what an alert on that parent will catch.

08 / what is in the starter csv

What is in the starter CSV

The free starter list CSV has 42 rows, one per code, and five columns:

  • cpv_code — the eight-digit code, without the check digit;
  • official_description — the CPV 2008 wording;
  • group — the table it belongs to on this page (Pumps and compressors, Valves, Water and process, Instrumentation, Pipework, Works, Maintenance, Installation, or Parent);
  • alert_tier — A or B, explained below;
  • notes — a short reminder where a code needs one.

34 rows are tier A: the product codes. 8 are tier B: the division 42000000 and the works, maintenance and installation codes. Delete the rows you do not sell, then load the rest into each portal's alert settings. Import the file as text so spreadsheet software does not drop or reformat the codes.

09 / how to use the list

How to use the list

  1. Build two alert tiers. Tier A covers your exact product codes, such as 42122220 Sewage pumps. Tier B covers the parent division and the works or maintenance codes, such as 42000000, 45252000 and 50511000. Tier B is noisier, but it catches bundled packages.
  2. Run the same codes on every portal: TED, Irish eTenders and the UK's Find a Tender. Matching rules differ, as the next section shows.
  3. Read award notices, not just open tenders. The winning contractor on a 45252000 works contract will need pumps, valves and instruments. That contractor is your account.

Fictional example: A fictional instrumentation distributor alerts only on 38421000 Flow-measuring equipment and sees few notices. After adding 45252000 and 42996000, it finds several wastewater treatment works contracts where flow meters are inside a larger works package, and it adds the winning contractors to its account list for research. This example is fictional and only illustrates the method.

10 / set cpv alerts on etenders ted and find a tender

Set CPV alerts on eTenders, TED and Find a Tender

Irish eTenders. You pick CPV codes when you first register as a supplier, and eTenders' guide asks you to select every code relevant to your business.[9] Later, add codes from your supplier profile with the "Edit CPV Codes" button; the platform emails you newly published tenders that match them.[4] Since a July 2024 release, matching works on the code tree: the same code matches, and a top-level code matches any sub-code in its tree whichever side holds it. Two different sub-codes in the same tree do not match: eTenders' own example is 15131130 against 15131134.[5] So a supplier holding only 42122220 will not be alerted to a notice coded 42122230. List every exact code you sell, or accept the noise of a top-level code. Award emails only come for competitions you expressed an interest in.[4] Our Irish eTenders guide covers how to triage what arrives.

TED. With a free EU Login account you can save up to 25 searches and 25 search alerts, sent daily, weekly, fortnightly or monthly, or follow them by RSS. Build the search with the CPV filter and a place-of-performance filter, then save it.[6] See our TED EU tenders guide for the search settings.

Find a Tender. The notice search has a CPV code filter alongside notice type, location and suitability.[7][8] Select "save search", name it and choose how often you want the email.[8] Our UK public tenders guide explains which UK portal carries which notices.

11 / frequently asked questions

Frequently asked questions

What is the CPV code for pumps?

42122000 Pumps, which sits under 42120000 Pumps and compressors in division 42 (Industrial machinery). More specific codes include 42122130 Water pumps, 42122220 Sewage pumps and 42122230 Dosing pumps.[1][3]

What is the CPV code for valves?

42130000 Taps, cocks, valves and similar appliances. More specific codes include 42131142 Control valves, 42131260 Ball valves and 42131280 Butterfly valves; valve actuators are 42132100.[1][3]

What do the digits in a CPV code mean?

The first two digits are the division, the first three the group, the first four the class and the first five the category. The last three add precision within the category, and the ninth digit after the dash only verifies the others.[2]

Which CPV codes cover pump and valve maintenance?

50511000 Repair and maintenance services of pumps and 50512000 Repair and maintenance services of valves, both under 50510000. Buyers also use 45259000 Repair and maintenance of plant for works contracts.[1][3]

How do I get tender alerts by CPV code?

On Irish eTenders, add codes in your supplier profile with "Edit CPV Codes".[4] On TED, save a search with a CPV filter as an alert, using a free EU Login account.[6] On Find a Tender, filter by CPV code and select "save search".[8]
